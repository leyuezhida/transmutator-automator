### 修正一个玩家可见的错字

界面里一直有几处把「**嬗**变」写成了「**孖**变」。

`嬗`（shàn，更替、演变）和 `孖`（mā，双生子）字形相近，是本模组自己写错的。其中玩家能直接看到的一处是 `/ta` 命令的提示文字：

```
旧：面板就在孖变台界面左侧。
新：面板就在嬗变台界面左侧。
```

另外 README、CurseForge 材料与若干代码注释里的同类错字一并修正，共 14 处。

### 说明

功能与 v1.0.2 完全一致。如果你不在意命令提示里那个字，可以不升级。
